# Customer Churn Analysis and Prediction System

## Overview

This project predicts whether a telecom customer is likely to churn (leave the service) using Machine Learning.

A Random Forest Classifier was trained on the Telco Customer Churn dataset and deployed using Streamlit for interactive predictions.

---

## Dataset

* Telco Customer Churn Dataset
* 7043 customer records
* 33 customer attributes

---

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-Learn
* Streamlit
* Joblib

## Machine Learning Model

Random Forest Classifier

### Performance

* Accuracy: 78%
* Precision: 82%
* Recall: 89%
* F1 Score: 86%

---

## Key Insights

* Month-to-Month customers have the highest churn rate.
* Electronic Check users are more likely to churn.
* Customers without Tech Support show higher churn.
* Fiber Optic users churn more frequently than DSL users.

---


## Streamlit Application

The Streamlit web application allows users to:

* Enter customer information
* Predict churn probability
* View Stay vs Churn percentage
* Get real-time prediction results

# Customer Churn Analysis and Prediction System

## Overview

This project analyzes telecom customer data and predicts whether a customer is likely to churn using Machine Learning.

## Dataset

* Telecom Customer Churn Dataset
* 7043 customer records
* 33 business attributes

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-Learn
* Streamlit

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Feature Engineering
5. Data Encoding
6. Machine Learning Model Training
7. Model Evaluation
8. Streamlit Web Application

## Model

Random Forest Classifier

### Performance

* Accuracy: 78%
* Customer Churn Prediction

## Key Business Insights

* Month-to-Month customers have the highest churn rate.
* Fiber Optic customers show higher churn compared to DSL customers.
* Electronic Check users have the highest churn rate.
* Customers without Tech Support are more likely to churn.

## Streamlit Application

The Streamlit application allows users to enter customer information and receive churn predictions along with churn probability.
